FINCONTROL · COMECE AQUI

Seu financeiro, sem complicação.

Você pode começar no seu próprio computador, sem contratar hospedagem.

1. Abra no computador

  1. Extraia o ZIP. Coloque a pasta em Documentos ou onde preferir. Não execute de dentro do arquivo compactado.
  2. Instale o SDK .NET 8, se ainda não estiver instalado. Escolha o instalador SDK para seu sistema.
  3. No Windows, abra INICIAR.bat. A primeira execução precisa de internet para preparar as dependências.
  4. Abra http://localhost:5078. Se o navegador abrir antes do programa iniciar, atualize a página.
  5. Clique em Criar conta. Escolha Pessoal, MEI ou Empresa.
Deixe a janela do FinControl aberta. Ao fechá-la, o sistema para de responder; seus registros continuam guardados no banco.

No macOS/Linux: instale o SDK .NET 8 e execute bash iniciar.sh no terminal, dentro da pasta extraída.

2. Use no celular ou tablet

  1. Feche uma execução anterior e abra INICIAR-NA-REDE.bat no computador.
  2. Conecte os dispositivos ao mesmo Wi-Fi de confiança.
  3. Localize o IPv4 da conexão ativa, exibido na janela. Exemplo: 192.168.1.20.
  4. No celular, abra http://192.168.1.20:5078, substituindo pelo IP verdadeiro do computador.

O computador precisa permanecer ligado. Se o Windows pedir permissão de firewall, permita somente rede privada. Para acesso fora dessa rede, consulte docs/HOSPEDAGEM.md.

3. Organize o seu espaço

OndeO que fazer
Contas e carteirasCadastre suas contas e informe o saldo inicial.
Novo lançamentoInforme receitas/despesas e marque o que já foi pago ou recebido.
Orçamentos e metasPlaneje limites por categoria e acompanhe suas reservas.
RecorrênciasGere vencimentos periódicos como pendentes.
ConfiguraçõesEscolha tema, crie espaços separados, adicione membros e faça backups.
Importar extratoSelecione CSV/OFX, confira a prévia e só então confirme.
Faça backups. Configurações → Baixar backup. Para recuperar, use Restaurar backup; será criado outro espaço, sem apagar o atual.

Preciso pagar um servidor?

Não, para usar localmente. Seu próprio computador executa o sistema. Hospedagem remota é opcional, para acesso de qualquer lugar sem depender desse computador.

A instalação no celular como aplicativo depende do navegador e de HTTPS. O acesso normal pelo navegador funciona pela rede local; os registros financeiros precisam de conexão com a instalação.

Sobre esta versão

A interface renovada é a versão web. O projeto Windows original foi mantido com correções. O FinControl atende controle financeiro e caixa de equipes pequenas; não substitui um ERP, sistema contábil ou emissão fiscal.

Todos os detalhes, limites e instruções técnicas estão em README.md e docs/VALIDACAO.md.
